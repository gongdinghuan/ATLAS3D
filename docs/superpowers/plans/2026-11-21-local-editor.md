# Atlas 本地工作台实现计划

按用户选定的「本地运行编辑器，生成和重建调用 Atlas 官方 API」实施。可选的第三方服务从兼容的文生图协议开始接入。目标行为与验证范围见项目根目录的 REA 核验记录。

1. 在本机 Node 服务内保存项目和素材。文件写入完成后替换旧版本，版本冲突时保留用户当前编辑。验证重启读取、并发写入和素材路径边界。
2. 实现三维白模编辑器。验证物体选择与变换、灯光、取景、关键帧路径、截图与 OBJ 导出。
3. 实现服务端模型适配。校对六个 Atlas 任务和第三方文生图的协议，使用受控响应检查请求、轮询和故障处理。
4. 将输入素材、相机、前序任务结果和本地工作台连接起来。用浏览器操作测试常用流程，记录未用真实账号验证的操作。
